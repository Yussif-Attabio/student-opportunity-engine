## Fallback Behavior

When AI request fails:
1. Error is logged to browser console (for debugging)
2. System automatically uses local guidance generation
3. User sees guidance without noticing the failure
4. UI shows "Application Guidance" instead of "AI Application Guidance"
5. All functionality remains intact

## Quick Start

1. Copy .env.example to .env.local
2. Add your API key:

3. Run: npm run dev
4. Open opportunity modal to test AI guidance
